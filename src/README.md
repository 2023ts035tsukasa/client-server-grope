# ソースコード

プログラムや実装コードを配置するディレクトリです。
`code-template/` 以下に、言語別の最小構成を用意しています。

## 含まれるテンプレート

| ディレクトリ | 内容 |
|--------------|------|
| `code-template/c-template/` | Makefile 付きの C 言語テンプレート |
| `code-template/python-template/` | Python テンプレート |
| `code-template/go-template/` | Go テンプレート |
| `code-template/rust-template/` | Rust テンプレート |

## 推奨される使い方

- 利用する言語のテンプレートを参考に、自分の課題用のファイル構成へ変更すること
- 実行方法や必要な環境は、ルートの `README.md` またはこのディレクトリ内の README に追記すること
- 生成物、キャッシュ、仮想環境などはコミットしないこと
