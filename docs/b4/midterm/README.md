# 卒業研究 中間発表要旨

このディレクトリには、卒業研究中間発表要旨を格納します。

## ファイル構成

```text
midterm/
├── main.tex
├── references.bib
├── figures/
├── main.pdf
├── Makefile
├── .latexmkrc
└── README.md
```

各ファイルの用途は次のとおりです。

- `main.tex`
  - 要旨本文
- `references.bib`
  - 参考文献
- `figures/`
  - 図・グラフ
- `main.pdf`
  - コンパイル済みPDF
- `Makefile`
  - コンパイル用
- `.latexmkrc`
  - LuaLaTeX / upLaTeX の設定

## コンパイル方法

学科のテンプレートでは、LuaLaTeXまたはupLaTeXを使用します。

### 通常

```bash
make
```

を実行してください。

標準ではLuaLaTeXを使用して `main.pdf` を生成します。

次のコマンドと同じ意味です。

```bash
make lua
```

### upLaTeXを使用する場合

```bash
make up
```

を実行してください。

この場合は、

```text
upLaTeX
   ↓
DVI
   ↓
dvipdfmx
   ↓
PDF
```

の順に処理されます。

通常は、どちらか一方の方法で正常にPDFを生成できればかまいません。

## 編集するファイル

基本的には次のファイルだけを編集してください。

- `main.tex`
- `references.bib`
- `figures/` 以下の図

学科指定の書式を維持するため、特に指示がない限り、

- `documentclass`
- 用紙サイズ
- 余白
- フォントサイズ
- 行間

などの書式設定は変更しないでください。

2ページに収まらない場合は、フォントや余白を小さくして
無理に収めるのではなく、まず文章や図表の内容を整理してください。

## GitHubへ登録するファイル

少なくとも次のファイルをcommitしてください。

- `main.tex`
- `references.bib`
- 使用した図・グラフ
- `main.pdf`

LaTeXのコンパイル時に生成される、

```text
*.aux
*.log
*.dvi
*.bbl
*.blg
```

などの一時ファイルはcommitしないでください。

`main.pdf` はレビュー時に確認するため、GitHubへ登録してください。

原稿を修正して再コンパイルした場合は、
`main.pdf` も忘れずに更新してください。

## 第1稿の条件

第1稿は完成稿である必要はありませんが、
最初から最後まで通して読むことのできる原稿にしてください。

提出前に以下を確認してください。

- [ ] 題目・学籍番号・氏名が正しい
- [ ] PDFが2ページに収まっている
- [ ] すべての節に文章が入っている
- [ ] 研究背景と研究目的が説明されている
- [ ] 現時点で行ったことが説明されている
- [ ] 現時点で得られている結果が示されている
- [ ] 今後の計画が具体的に書かれている
- [ ] 図または表が1点以上ある
- [ ] 参考文献がある
- [ ] 本文から参考文献を引用している
- [ ] `make` または `make up` でエラーなくPDFを生成できる
- [ ] `main.pdf` が最新版になっている

## 内容についての注意

特に、次の3つを区別して書いてください。

1. 卒業研究として最終的に目指していること
2. 中間発表までに実際に行ったこと
3. 中間発表後に行う予定のこと

まだ実施していない内容を、すでに実施したように書いてはいけません。

逆に、十分な実験結果が得られていない場合でも、
結果の節を空欄にはしないでください。

現時点で、

- 何を実装したか
- 何を試したか
- 何が確認できたか
- 何がまだ確認できていないか

を書いてください。

## 参考文献の追加と引用

参考文献は `references.bib` に登録します。

例えば、次の文献が登録されているとします。

```bibtex
@misc{kubernetes,
  author       = {{Kubernetes Authors}},
  title        = {Kubernetes Documentation: Overview},
  howpublished = {\url{https://kubernetes.io/docs/concepts/overview/}},
  note         = {参照 2026-09-XX}
}
```

`kubernetes` の部分が、この文献を識別するためのキーです。

本文では、

```latex
Kubernetesでは，コンテナ化されたアプリケーションの
配置や管理を自動化できる\cite{kubernetes}。
```

のように引用します。

複数の文献をまとめて引用する場合は、

```latex
\cite{kubernetes,marchese2022}
```

のように記述します。

### 参考文献を追加した後のコンパイル

通常どおり、

```bash
make
```

を実行してください。

BibTeXを別に実行する必要はありません。

`latexmk` が、

1. LaTeXのコンパイル
2. upBibTeXによる参考文献の生成
3. 引用番号を反映するための再コンパイル
4. 必要に応じた追加の再コンパイル

を自動的に行います。

### 注意

`references.bib` に文献を登録しただけでは、
通常は参考文献一覧には表示されません。

本文中で、

```latex
\cite{文献キー}
```

を使って引用してください。

また、テンプレートに最初から入っているサンプル文献は、
自分の要旨で使用しない場合は提出前に削除してください。
