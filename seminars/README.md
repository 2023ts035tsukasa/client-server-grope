# ゼミ

ゼミ内ワーク、ゼミで作成する資料、作業結果などを配置するディレクトリです。

学生は各回のゼミで、ゼミ内ワーク用の Markdown ファイルを作成し、GitHub に push してください。
このファイルには、自分の報告内容だけでなく、他の学生の発表や教員コメントから自分の作業に活かせることも記録します。
他人に対する高度なコメントを書くことが目的ではなく、自分の作業を改善するためのメモとして使います。

## テンプレート

| ファイル | 内容 |
|----------|------|
| `templates/seminar_notes.md` | 各回のゼミ内ワーク用 Markdown テンプレート |

## 推奨される使い方

- `templates/seminar_notes.md` をコピーして、各回のゼミ用ファイルを作成すること
- ファイル名には日付や回数が分かる名前を付けること
- 自分の次回作業に反映できる内容を具体的に書くこと
