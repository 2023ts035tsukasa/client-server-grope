# <プロジェクトタイトル>

> **概要** - ここにプロジェクトの1〜2文の説明を書きます。

このリポジトリは、宮澤研究室での課題提出・レポート執筆・発表資料作成・プロジェクト進行に使う学生用テンプレートです。
`<>` で囲まれた箇所や各テンプレート内の例文を、自分の課題・研究内容に合わせて書き換えてください。

## ディレクトリ構成

| ディレクトリ | 内容 |
|-------------|------|
| `src/`      | プログラム、実装コード、言語別の初期テンプレート |
| `reports/` | レポート本文、Markdown / LaTeX のレポート雛形 |
| `slides/`  | 発表資料、PowerPoint / Beamer / Markdown のスライド雛形 |
| `seminars/` | ゼミ内ワーク、ゼミで作成する資料や作業結果 |
| `docs/`    | 補足資料、仕様書、メモ |
| `data/`    | 実験データ、入力データ、結果データ |

## 使い始めるとき

```bash
git clone https://github.com/miyazawa-lab/<repo>.git
cd <repo>
```

コードを書く場合は、`src/code-template/` 以下にある自分の利用言語に近いテンプレートを参考にしてください。

| 言語 | テンプレート |
|------|--------------|
| C | `src/code-template/c-template/` |
| Python | `src/code-template/python-template/` |
| Go | `src/code-template/go-template/` |
| Rust | `src/code-template/rust-template/` |

## 提出前の確認

- README のプロジェクトタイトルと概要を自分の内容に更新すること
- レポート、スライド、コードには必要に応じて氏名・学籍番号・日付を明記すること
- 不要な生成物や一時ファイルをコミットしないこと
- Pull Request を作成するときは、テンプレートの各項目を埋めること
- AI を利用した場合は、Pull Request テンプレートの AI 利用欄に概要を書くこと
