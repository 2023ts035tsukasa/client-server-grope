# レポート

課題レポートや研究レポートを配置するディレクトリです。
指定された形式に合わせて、Markdown または LaTeX のテンプレートを使ってください。

## 含まれるテンプレート

| ファイル | 内容 |
|----------|------|
| `report-template.md` | Markdown 形式のレポート雛形 |
| `report-template.tex` | LaTeX 形式のレポート雛形 |

## 推奨される使い方

- ファイル名は課題名や提出日が分かる名前に変更すること
- レポートには氏名・学籍番号・日付を明記すること
- 図表や参考文献を使う場合は、本文中から参照できるように整理すること
