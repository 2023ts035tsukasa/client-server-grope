# 発表資料

発表スライドを配置するディレクトリです。
授業・ゼミ・研究発表の指定に合わせて、PowerPoint、Beamer、Markdown のいずれかを使ってください。

## 含まれるテンプレート

| ファイル | 内容 |
|----------|------|
| `presentation-template.pptx` | PowerPoint 用テンプレート |
| `beamer-presentation-template.tex` | Beamer 用テンプレート |
| `slide-template.md` | Markdown 形式のスライド雛形 |

## 推奨される使い方

- 発表タイトル、氏名、学籍番号、日付を自分の内容に更新すること
- 図表やスクリーンショットは、発表時に読める解像度で配置すること
- 課題や発表会で指定された形式がある場合は、その指示を優先すること
